# Support

## Getting help

For questions about using or developing this project:

- Search existing [issues](https://github.com/MaxAndreev27/nestjs/issues) first.
- Open a new issue using the appropriate template when the answer is not already documented.
- Include the Node.js version, operating system, relevant configuration, reproduction steps,
  and the complete error output with secrets removed.

## What not to use public support for

Do not disclose passwords, tokens, API keys, personal data, database dumps, or other
secrets in issues or pull requests. Report security vulnerabilities privately using
[SECURITY.md](SECURITY.md).

This project is maintained by volunteers, so response times are not guaranteed.
