# Security Policy

## Supported versions

Security fixes are provided for the latest version on the `main` branch. Older
versions may not receive security updates.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, pull requests, or
discussions.

Use GitHub's private vulnerability reporting for this repository when available:

<https://github.com/MaxAndreev27/nestjs/security/advisories/new>

If private reporting is unavailable, contact the repository owner through the
private contact options on their GitHub profile:

<https://github.com/MaxAndreev27>

Include:

- A clear description of the vulnerability and its potential impact.
- Steps to reproduce or a proof of concept.
- The affected version, commit, endpoint, or configuration.
- Any suggested mitigation, if known.

Please avoid accessing, modifying, or deleting data that does not belong to you.
We will acknowledge valid reports as soon as practical, investigate them, and
coordinate disclosure and a fix with the reporter.
