# Governance

## Maintainers

The repository is currently maintained by [Max Andreev](https://github.com/MaxAndreev27).
Maintainers review contributions, manage releases, and make decisions about the
project's direction.

## Decision making

Technical decisions are made in public issues and pull requests whenever possible.
For larger changes, contributors should first open an issue describing the problem,
the proposed solution, and relevant trade-offs.

Maintainers consider project scope, correctness, security, maintainability, test
coverage, and backward compatibility when reviewing changes.

## Becoming a maintainer

Consistent, constructive contributions may lead to an invitation to become a
maintainer. The current maintainers make this decision based on demonstrated
technical judgment, communication, and understanding of the project.

## Changes to this policy

Governance changes should be proposed through a pull request and reviewed publicly.
